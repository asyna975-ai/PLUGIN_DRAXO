DEVELOPER NOTES

راهنمای سریع API

چند نمونه کوتاه برای شروع کدنویسی پلاگین‌های PocketMine-MP.

01 / LIFECYCLE

شروع پلاگین

protected function onEnable() : void{
    $this->getLogger()->info("Plugin enabled");
}

این متد هنگام فعال‌شدن پلاگین فراخوانی می‌شود.

02 / COMMANDS

ثبت دستور

public function onCommand(
    CommandSender $sender,
    Command $command,
    string $label,
    array $args
) : bool { return true; }

دستور باید در plugin.yml تعریف شود.

03 / MANIFEST

plugin.yml

name: DRAXOPlugin
main: DRAXO\\Main
version: 1.0.0
api: ["5.0.0"]

نسخه API را مطابق نسخه نصب‌شده سرور تعیین کن.
